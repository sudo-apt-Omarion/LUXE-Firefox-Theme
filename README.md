## Manual Installation (Core CSS Only)
If you prefer to configure everything manually using the open-source files in this repository:
1. Open Firefox and type `about:support` in the URL bar.
2. Find the **Profile Folder** row and click **Open Folder**.
3. Create a folder named `chrome` inside your profile directory if it doesn't exist.
4. Download the `userChrome.css` and `userContent.css` files from this repository and place them inside the `chrome` folder.
5. Go to `about:config` in Firefox, search for `toolkit.legacyUserProfileCustomizations.stylesheets`, and set it to **true**.
6. Restart Firefox.
